# Beginner Learning Path - ML/AI Operations

## Overview

This beginner path covers ML/AI Operations concepts and practices, progressing from fundamentals to practical application with Claude Code plugins.

## Prerequisites

- Python programming basics\n- Basic statistics knowledge\n- Understanding of linear algebra

## Modules

### Module 1: ML Fundamentals

#### Concepts
- Supervised vs unsupervised learning\n- Training, validation, test splits\n- Loss functions and optimization\n- Overfitting and regularization\n- Basic model evaluation metrics

#### Hands-On Exercise
Apply the concepts using the relevant plugins. Start simple, build complexity gradually.

#### Key Takeaways
- Understand the fundamentals of ML Fundamentals
- Know when to apply these patterns
- Create basic implementations confidently

---

### Module 2: First Model Training

#### Concepts
- Setting up a Python ML environment\n- Loading and preprocessing data\n- Training a simple model with scikit-learn\n- Model evaluation and metrics\n- Saving and loading models

#### Hands-On Exercise
Build on Module 1 with more advanced techniques. Focus on quality and reproducibility.

#### Key Takeaways
- Integrate multiple concepts effectively
- Apply established best practices
- Evaluate and improve existing work

---

### Module 3: Introduction to Deep Learning

#### Concepts
- Neural network fundamentals\n- PyTorch basics (tensors, autograd)\n- Building a simple neural network\n- Training loops and callbacks\n- GPU vs CPU training

#### Hands-On Exercise
Combine everything into a comprehensive project demonstrating full mastery.

#### Key Takeaways
- Synthesize all module concepts
- Make informed architectural decisions
- Create production-quality implementations

## Assessment

- [ ] Complete all module exercises

- [ ] Review against skill file patterns
- [ ] Identify areas for deeper study

## Next Steps

Continue to **intermediate** for experiment tracking, feature engineering, and model versioning.
