# Beginner — ML in production

## Mindset shifts

1. **The model is the easy part.** Data, pipelines, monitoring, eval are the work.
2. **Reproducibility is mandatory.** Version data + code + config. "It worked in my notebook" isn't enough.
3. **Eval before optimization.** Measure first.
4. **Drift will happen.** Plan for it; monitor for it.
5. **ML is software engineering.** Tests, code review, CI/CD apply.
