# Intermediate Learning Path - ML/AI Operations

## Overview

This intermediate path covers ML/AI Operations concepts and practices, progressing from fundamentals to practical application with Claude Code plugins.

## Prerequisites

- Completed beginner path\n- Trained at least one ML model\n- Basic PyTorch or TensorFlow knowledge

## Modules

### Module 1: Experiment Tracking & Versioning

#### Concepts
- MLflow setup and usage\n- Weights & Biases integration\n- Hyperparameter logging\n- Model versioning with DVC\n- Reproducible experiments

#### Hands-On Exercise
Apply the concepts using the relevant plugins. Start simple, build complexity gradually.

#### Key Takeaways
- Understand the fundamentals of Experiment Tracking & Versioning
- Know when to apply these patterns
- Create basic implementations confidently

---

### Module 2: Feature Engineering & Data Pipelines

#### Concepts
- Feature extraction techniques\n- Feature stores (Feast)\n- Data preprocessing pipelines\n- Data validation (Great Expectations)\n- ETL for ML workflows

#### Hands-On Exercise
Build on Module 1 with more advanced techniques. Focus on quality and reproducibility.

#### Key Takeaways
- Integrate multiple concepts effectively
- Apply established best practices
- Evaluate and improve existing work

---

### Module 3: Model Deployment Basics

#### Concepts
- Model serving with FastAPI\n- Docker containers for ML\n- TorchServe and TF Serving\n- A/B testing models\n- Monitoring model performance

#### Hands-On Exercise
Combine everything into a comprehensive project demonstrating full mastery.

#### Key Takeaways
- Synthesize all module concepts
- Make informed architectural decisions
- Create production-quality implementations

## Assessment

Continue to **advanced** for distributed training, LLM fine-tuning, and production ML systems.
