# X mine: LibreMLOps-Claude-Code competitors

## How this fills

1. Take the top 5 to 8 names from the latest competitor map.
2. Search X for praise and complaints tied to **named matrix capabilities** (reliability, cost, DX, permissions, memory, multi-agent, verify), not brand vibes alone.
3. Fetch primary posts; quote short snippets with `x.com` links. **Never invent engagement counts or sentiment %.**
4. Save as `YYYY-MM-DD-x-mine.md` (keep this TEMPLATE).

## Search log (what we tried)

- Fetch method: WebFetch on an `x.com` post URL returned HTTP 402 (tried on https://x.com/mintlify/status/1856746045453349277 in the same session). Post text was fetched instead from X's own embed endpoint, `https://cdn.syndication.twimg.com/tweet-result?id=<post id>&token=a`, which returns the post's text, author and date. Links above are the `x.com` URLs of those posts. For long posts the endpoint returns only the opening text, and the snippets quote only what came back.
- WebSearch `site:x.com hugging face skills claude code fine-tune model`: hits used (Hesamation, LiorOnAI, akshay_pachaar, techNmak). Others returned but not used: a fine-tuning app built on Claude, a Japanese-language post, and two launch-recap posts.
- WebSearch `site:x.com AI Research Skills orchestra claude code vllm`: no posts about the AI-Research-SKILLs library. One Japanese-language post about serving a local model with vLLM for Claude Code, not used. Empty for this competitor.
- WebSearch `site:x.com orch_research AI research skills library claude code`: no posts about AI-Research-SKILLs; results were X articles and posts about other research-skill libraries. Empty for this competitor.
- WebSearch `site:x.com wandb MCP server claude`: hit used (wandb launch post). A post by a W&B employee about auto-logging Claude Code sessions was returned and not used; the rest were MCP posts from other vendors.
- WebSearch `site:x.com mlflow mcp server claude code traces`: hit used (MLflow). The rest were MCP posts from other vendors.
- WebSearch `site:x.com claude code jupyter notebook ML experiments problem`: hits used (JFPuget, helloiamleonie, eugeneyan, kmeanskaran, den_volkhonskiy).
- WebSearch `site:x.com claude code MLOps pipeline model deployment agent skill`: hit used (replicate). The rest were general Claude Code posts; nothing on MLOps pipelines or model deployment skills.
- Not searched on X: wshobson/agents ML plugins, mlops-coding-skills and the awesome-cursorrules ML rules by name. The session's WebSearch budget was used up before these (the tool refused further calls), so there is no X evidence for them in this run.
