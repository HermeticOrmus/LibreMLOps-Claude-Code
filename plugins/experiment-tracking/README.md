# Experiment Tracking

MLflow, W&B, experiment organization, hyperparameter logging

## What's Included

### Agents
- **Experiment Tracker** - Specialized agent for MLflow, W&B, experiment organization, hyperparameter logging

### Commands
- `/track-experiment` - Quick-access command for experiment-tracking workflows

### Skills
- **Experiment Tracking Patterns** - Pattern library and knowledge base for experiment-tracking

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/track-experiment analyze

# Use the command with specific input
/track-experiment generate --context "your project"

# Reference patterns from the skill
"Apply experiment-tracking-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for experiment-tracking
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
