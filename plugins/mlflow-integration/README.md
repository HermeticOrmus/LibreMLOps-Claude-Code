# Mlflow Integration

MLflow setup, tracking server, model registry, deployments

## What's Included

### Agents
- **Mlflow Engineer** - Specialized agent for MLflow setup, tracking server, model registry, deployments

### Commands
- `/mlflow` - Quick-access command for mlflow-integration workflows

### Skills
- **Mlflow Patterns** - Pattern library and knowledge base for mlflow-integration

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/mlflow analyze

# Use the command with specific input
/mlflow generate --context "your project"

# Reference patterns from the skill
"Apply mlflow-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for mlflow-integration
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
