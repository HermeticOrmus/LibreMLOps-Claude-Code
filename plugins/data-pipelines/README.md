# Data Pipelines

ETL for ML, data preprocessing, Apache Beam/Spark

## What's Included

### Agents
- **Ml Data Engineer** - Specialized agent for ETL for ML, data preprocessing, Apache Beam/Spark

### Commands
- `/ml-pipeline` - Quick-access command for data-pipelines workflows

### Skills
- **Ml Pipeline Patterns** - Pattern library and knowledge base for data-pipelines

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/ml-pipeline analyze

# Use the command with specific input
/ml-pipeline generate --context "your project"

# Reference patterns from the skill
"Apply ml-pipeline-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for data-pipelines
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
