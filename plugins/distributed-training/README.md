# Distributed Training

Multi-GPU, distributed data parallel, model parallel

## What's Included

### Agents
- **Distributed Training Engineer** - Specialized agent for Multi-GPU, distributed data parallel, model parallel

### Commands
- `/dist-train` - Quick-access command for distributed-training workflows

### Skills
- **Distributed Training Patterns** - Pattern library and knowledge base for distributed-training

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/dist-train analyze

# Use the command with specific input
/dist-train generate --context "your project"

# Reference patterns from the skill
"Apply distributed-training-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for distributed-training
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
