# Model Evaluation

Metrics, evaluation frameworks, bias detection, fairness

## What's Included

### Agents
- **Model Evaluator** - Specialized agent for Metrics, evaluation frameworks, bias detection, fairness

### Commands
- `/evaluate-model` - Quick-access command for model-evaluation workflows

### Skills
- **Model Evaluation Patterns** - Pattern library and knowledge base for model-evaluation

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/evaluate-model analyze

# Use the command with specific input
/evaluate-model generate --context "your project"

# Reference patterns from the skill
"Apply model-evaluation-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for model-evaluation
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
