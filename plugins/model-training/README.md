# Model Training

Training loops, callbacks, checkpointing, early stopping

## What's Included

### Agents
- **Training Engineer** - Specialized agent for Training loops, callbacks, checkpointing, early stopping

### Commands
- `/train-model` - Quick-access command for model-training workflows

### Skills
- **Training Patterns** - Pattern library and knowledge base for model-training

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/train-model analyze

# Use the command with specific input
/train-model generate --context "your project"

# Reference patterns from the skill
"Apply training-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for model-training
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
