# Gpu Optimization

CUDA optimization, mixed precision, memory management

## What's Included

### Agents
- **Gpu Optimizer** - Specialized agent for CUDA optimization, mixed precision, memory management

### Commands
- `/gpu-optimize` - Quick-access command for gpu-optimization workflows

### Skills
- **Gpu Optimization Patterns** - Pattern library and knowledge base for gpu-optimization

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/gpu-optimize analyze

# Use the command with specific input
/gpu-optimize generate --context "your project"

# Reference patterns from the skill
"Apply gpu-optimization-patterns patterns to this implementation"
```
