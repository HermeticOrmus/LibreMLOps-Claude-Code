# Tensorflow Patterns

TF/Keras models, tf.data, SavedModel, TFLite

## What's Included

### Agents
- **Tensorflow Engineer** - Specialized agent for TF/Keras models, tf.data, SavedModel, TFLite

### Commands
- `/tensorflow` - Quick-access command for tensorflow-patterns workflows

### Skills
- **Tensorflow Patterns** - Pattern library and knowledge base for tensorflow-patterns

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/tensorflow analyze

# Use the command with specific input
/tensorflow generate --context "your project"

# Reference patterns from the skill
"Apply tensorflow-patterns patterns to this implementation"
```
