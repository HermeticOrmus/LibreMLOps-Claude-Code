# Rag Architecture

Retrieval-augmented generation, chunking, embeddings

## What's Included

### Agents
- **Rag Architect** - Specialized agent for Retrieval-augmented generation, chunking, embeddings

### Commands
- `/rag` - Quick-access command for rag-architecture workflows

### Skills
- **Rag Patterns** - Pattern library and knowledge base for rag-architecture

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/rag analyze

# Use the command with specific input
/rag generate --context "your project"

# Reference patterns from the skill
"Apply rag-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for rag-architecture
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
