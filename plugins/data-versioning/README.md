# Data Versioning

DVC, dataset versioning, data lineage tracking

## What's Included

### Agents
- **Data Version Engineer** - Specialized agent for DVC, dataset versioning, data lineage tracking

### Commands
- `/data-version` - Quick-access command for data-versioning workflows

### Skills
- **Data Versioning Patterns** - Pattern library and knowledge base for data-versioning

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/data-version analyze

# Use the command with specific input
/data-version generate --context "your project"

# Reference patterns from the skill
"Apply data-versioning-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for data-versioning
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
