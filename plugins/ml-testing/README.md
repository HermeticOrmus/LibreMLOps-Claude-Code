# Ml Testing

Model testing, data testing, behavioral testing, A/B testing

## What's Included

### Agents
- **Ml Test Engineer** - Specialized agent for Model testing, data testing, behavioral testing, A/B testing

### Commands
- `/ml-test` - Quick-access command for ml-testing workflows

### Skills
- **Ml Testing Patterns** - Pattern library and knowledge base for ml-testing

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/ml-test analyze

# Use the command with specific input
/ml-test generate --context "your project"

# Reference patterns from the skill
"Apply ml-testing-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for ml-testing
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
