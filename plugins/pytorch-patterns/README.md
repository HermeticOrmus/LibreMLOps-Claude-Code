# Pytorch Patterns

PyTorch modules, datasets, DataLoaders, Lightning

## What's Included

### Agents
- **Pytorch Engineer** - Specialized agent for PyTorch modules, datasets, DataLoaders, Lightning

### Commands
- `/pytorch` - Quick-access command for pytorch-patterns workflows

### Skills
- **Pytorch Patterns** - Pattern library and knowledge base for pytorch-patterns

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/pytorch analyze

# Use the command with specific input
/pytorch generate --context "your project"

# Reference patterns from the skill
"Apply pytorch-patterns patterns to this implementation"
```
